## 1. 문서 목적

이 PRD는 music-mood-recs의 **Phase 2(LLM 확장)** 범위를 정의한다.

- **다루는 범위**: ① 텍스트 무드 판정의 키워드 휴리스틱 → LLM 3단 폴백 체인 교체, ② 데이터셋 내부 곡 한정 추천 → 실제 발매 음원 Top-5 확장(검색 링크 제공), ③ 기존 DL 파이프라인·제출 구조 무손상 보장.
- **다루지 않는 범위**: 스트리밍 서비스 OAuth 연동·직접 재생(Phase 1의 원래 범위), LLM 파인튜닝, RAG 지식베이스, 사용자 계정.
- **이 문서로 내릴 결정**: LLM 공급자 체인 구성, 환각 대응 방식, 기존 코드 변경 최소화 전략.

## 2. 프로젝트 개요

Phase 0의 MoodCNN(오디오 무드 분류 + 임베딩 추천)은 그대로 유지하면서, LLM으로 두 가지 입출력 경계를 확장한다: **입력** — 사용자의 자연어 문장을 LLM이 5개 학습 태그로 매핑(기존: 한국어 키워드 매칭), **출력** — LLM이 무드에 맞는 실존 곡을 제안하고 iTunes 카탈로그로 검증해 Spotify·YouTube Music·Apple Music 링크와 함께 노출(기존: 데이터셋 내부 무명 곡만).

| 항목 | 값 |
| --- | --- |
| LLM | Ollama 로컬(gemma3:4b, 무료) → Groq 무료 API(llama-3.3-70b) → 키워드 휴리스틱 3단 폴백 |
| 음원 검증 | iTunes Search API (무료·키 불필요) |
| 신규 코드 | `src/llm/mood_analyzer.py` · `src/llm/music_search.py` (기존 모듈 수정 없음) |
| 제출 연동 | `sync_standalone_app.py` BLOCKS 추가, `make_notebook.py` §9 셀 추가 |

## 3. 프로젝트 목표

### 3.1 문제 정의

- **사용자가 원하는 결과**: 기분을 문장으로 쓰면 정확한 무드로 이해받고, 실제로 들을 수 있는 유명 곡을 추천받는 것.
- **현재 상태의 고통**: ① 키워드 매칭은 사전에 등록된 표현만 인식("싱숭생숭해" 같은 문장 실패), ② 추천 결과가 Jamendo 무명 곡뿐이라 "그래서 뭘 들으라는 건지" 알 수 없음(Phase 0 P1 이월 사유).
- **근거 출처 또는 확신 수준**: High — Phase 0 STATUS.md P1 항목으로 명시 이월됨.

## 6. 인수 조건 (핵심)

```text
Given Ollama·Groq 모두 사용 불가(오프라인)
When 사용자가 "오늘 너무 우울해"를 입력
Then 키워드 휴리스틱으로 dark가 추정되고, 라이브러리 Top-5는 정상 표시되며,
     실음원 섹션은 실패 안내만 노출(앱 크래시 없음)
```

```text
Given LLM이 실존하지 않는 곡을 제안
When iTunes 검증이 0건 매칭
Then 해당 곡은 제외되고 무드 키워드 검색 결과로 채워진다
```

## 8. 성공 지표

- 정량: 기존+신규 pytest 전부 통과(54건), Streamlit Cloud에서 3개 입력 모드 + 실음원 섹션 정상 동작.
- 정성: 키워드 사전에 없는 문장("싱숭생숭해서 뭘 해야 할지 모르겠어")이 합리적 무드로 매핑됨(발표 시연 시나리오).

## 9. 가정과 검증

| 가정 | 근거 수준 | 틀렸을 때의 위험 | 검증 계획 |
| --- | --- | --- | --- |
| Groq 무료 티어가 시연 시점에 유효 | Medium | 클라우드 시연에서 LLM 경로 미동작(휴리스틱 폴백으로 시연은 가능) | 시연 리허설에서 실호출 확인 |
| iTunes Search API 무인증 정책 유지 | High | 실음원 섹션 실패 안내로 강등 | 리허설 확인 |
| LLM 곡 제안의 iTunes 매칭률이 충분(≥50%) | Medium | 키워드 검색 채움 비율 증가(품질 저하) | 무드별 수동 스팟체크 |

## 10. 주요 리스크

- Streamlit Cloud secrets 미설정 시 클라우드 데모가 휴리스틱 경로로만 동작 → 배포 체크리스트에 `GROQ_API_KEY` 등록 포함.
- Groq rate limit(무료) — 시연 중 연속 호출 시 지연 가능 → 결과 1시간 캐시(`st.cache_data`)로 완화.
